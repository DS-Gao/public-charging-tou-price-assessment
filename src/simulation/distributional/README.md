# Distributional known-truth simulation

This directory contains a portable implementation of the 24-scenario V2 synthetic distributional experiment and the scenario 16 high-inner-resample diagnostic. The generator uses only the declared six-type synthetic population in simulation_design.md; it does not read original transaction data.

## Install

From the package root, install the released dependency lock:

~~~sh
python -m pip install -r requirements-lock.txt
~~~

The historical environment in run_manifest.json is a record of the environment that produced the frozen results. It is not an installation specification for this package.

## Frozen historical results

The preserved formal outputs are under data/reference/historical/window_and_mixture_validation/v2/formal/. They include scenario definitions, truth, progress, performance summaries, outer station counts, 24 saved scenario-replicate parquet files, and the scenario 16 adaptive summary and replicate parquet. These are synthetic simulation artifacts; no original transaction data are included.

## Run a new synthetic experiment

Choose a new or empty directory outside the frozen formal-result directory:

~~~sh
python src/simulation/distributional/v2_mixture_simulation.py --phase pilot --replicates 200 --bootstrap 399 --seed 9132602 --output ../v2-pilot-output
~~~

For a formal-sized synthetic rerun, use phase formal, 2,000 replicates, 1,999 bootstrap samples, seed 9132602, and a separate new output directory. The script refuses to write into the preserved formal-result directory and refuses nonempty output directories.

## Run the adaptive scenario 16 diagnostic

The diagnostic is intentionally separate because it requires a compatible formal run generated by the script above:

~~~sh
python src/simulation/distributional/v2_targeted_refinement.py --formal-input ../v2-formal-output --output ../v2-scenario16-adaptive-output
~~~

Its default seed namespace is 9132602; it reuses the historical sequence definition and compares the first 1,999 inner resamples against saved formal intervals before calculating the 7,999-inner diagnostic.

## Verify implementation logic

The independent verifier checks the known-truth formula, zero-count behavior, critical scenario, a small exact-bootstrap case, frozen summaries, and the saved formal scenario 16 replicate arithmetic:

~~~sh
python src/simulation/distributional/verify_v2_independent.py --formal-dir data/reference/historical/window_and_mixture_validation/v2/formal --output ../v2-independent-checks.json
~~~

The frozen results document one specified synthetic design. They do not establish latent-price coverage for observed charging-price data.
